# MediaCatch 📥 — دانلودر هوشمند رسانه برای کروم

افزونه‌ای سبک برای Chrome (Manifest V3) در سبک **ADM Download Manager** که تصاویر، ویدیوها و فایل‌های صوتی قابل دانلود را در هر صفحه‌ای پیدا می‌کند و **دکمه دانلود کنار همان محتوا** نمایش می‌دهد؛ با یک کلیک، دانلود شروع می‌شود.

## قابلیت‌ها

- ✅ **تشخیص خودکار** انواع رسانه در صفحه:
  - `<img>` — حتی تصویرهای lazy-load (منابع `data-src` و مشابه)
  - `<video>` و `<audio>` و تگ‌های `<source>` داخلی
  - تصاویر **پس‌زمینه CSS** (inline + اسکن عمیق با computed style)
  - لینک‌های مستقیم به فایل‌های رسانه (png، jpg، mp3، mp4، m3u8 و…)
  - ویدیوهای **blob:** (پلی‌رهای MSE مثل بعضی اپلیکیشن‌های وب)
- ✅ **دکمه شناور هنگام هاور** — دقیقاً مثل ADM: نشانگر را روی رسانه نگه دارید، دکمه با نوع فایل و ابعاد کنارش ظاهر می‌شود
- ✅ **پنل «رسانه‌های صفحه»** — دکمه 📥 پایین صفحه: فهرست کامل با فیلتر (تصویر/ویدیو/صدا/استریم)، اسکن عمیق 🔍 و **دانلود همه**
- ✅ **منوی راست‌کلیک** — دانلود تصویر / صدا / ویدیو / لینک رسانه
- ✅ **میانبر کلید**: `Alt+D` دانلود رسانه زیر نشانگر — `Alt+Shift+D` باز/بستن پنل
- ✅ **شمارش رسانه‌ها روی آیکون نوارابزار** (بج عددی)
- ✅ **تاریخچه دانلودها** با وضعیت (در حال دانلود ✅ ⏳ ⚠️) و اندازه فایل
- ✅ **زنجیره دانلود مقاوم** — ۳ روش پشت‌سرهم:
  1. دانلود مستقیم
  2. اگر سرور دسترسی مستقیم را نداد (بررسی Referer/Cookie مثل اکثر سایت‌های موزیک) → fetch در context افزونه **با Cookie و Referer صفحه**
  3. اگر اون هم نشد → fetch **داخل خود صفحه** با context کامل صفحه
  - به‌علاوه: اگر دانلود بعد از شروع قطع شد (403 و…)، **خودکار** با روش جایگزین دوباره امتحان می‌شود
- ✅ **تنظیمات**: حداقل سایز تصویر (فیلتر آیکون و پیکسل‌های ردیابی)، پرسش محل ذخیره، دامنه‌های نادیده‌گرفته‌شده، خاموش/روشن کلی
- ✅ پشتیبانی از فریم‌های داخلی (iframe)

## نصب (Load Unpacked)

1. فایل `media-catch.zip` را دانلود و **آزمپ کنید** (یا مستقیم از فولدر `media-catch` استفاده کنید).
2. در کروم آدرس `chrome://extensions` را باز کنید.
3. گوشه صفحه، **Developer mode (حالت توسعه‌دهنده)** را روشن کنید.
4. روی **Load unpacked (بارگذاری بدون فشرده‌سازی)** بزنید و فولدر `media-catch` را انتخاب کنید.

> برای کار روی فایل‌های محلی (`file://`)، روی کارت افزونه → **Details** → «Allow access to file URLs» را روشن کنید.

## نحوه استفاده

| کار | روش |
|---|---|
| دانلود یک تصویر/ویدیو/صدا | نشانگر را روی محتوا نگه دارید → دکمه شناور → ⬇ |
| دیدن همه رسانه‌های صفحه | دکمه 📥 پایین صفحه (یا کلیک روی آیکون افزونه) |
| دانلود چندتایی | در پنل: «⬇ دانلود همه» (تا ۳۰ مورد) |
| تصاویر پس‌زمینه | در پنل: دکمه 🔍 «اسکن عمیق» |
| راست‌کلیک | روی تصویر/صدا/ویدیو/لینک رسانه: «دانلود … (MediaCatch)» |
| میانبر | `Alt+D` (هاور) — `Alt+Shift+D` (پنل) — قابل تغییر در `chrome://extensions/shortcuts` |

فایل‌ها در **پوشه دانلودها ← `media-catch`** ذخیره می‌شوند. اگر «پرسش محل ذخیره» روشن باشد، هر بار پنجره Save As را می‌بینید.

## تنظیمات

با راست‌کلیک روی آیکون افزونه → **Settings** (یا «تنظیمات کامل» در پایین popup):

- **تشخیص خودکار**: روشن/خاموش کردن کل افزونه
- **دکمه هنگام هاور**: نمایش دکمه شناور
- **پرسش محل ذخیره**: پنجره Save As برای هر دانلود
- **حداقل سایز تصویر**: تصویرهای کوچک‌تر نادیده گرفته می‌شوند (پیش‌فرض ۶۴px)
- **دامنه‌های نادیده‌گرفته‌شده**: هر دامنه در یک خط

## محدودیت‌ها (مهم بخوانید)

- این افزونه فایل‌های **مستقیم HTTP** را دانلود می‌کند. سایت‌هایی که محتوا را با روش اختصاصی سرو می‌کنند (مثل **YouTube**، اینستاگرام، آپارات و…) به «استریکتر اختصاصی هر سایت» نیاز دارند (ADM هم با اسکریپت جداگانه برای هر سایت این کار را می‌کند و در نسخه عمومی این افزونه نیست).
- استریم‌های **HLS/DASH** (`.m3u8` / `.mpd`) خودشان دانلود می‌شوند و با **VLC** قابل پخش/تبدیل‌اند؛ تبدیل آن‌ها به mp4 داخل افزونه نیست.
- بعضی سرورها (hotlink protection / CDN) اجازه دانلود مستقیم را نمی‌دهند؛ افزونه در این حالت **خودکار** از روش‌های جایگزین (fetch با Referer/Cookie صفحه) استفاده می‌کند. اگر سرور حتی با Referer صفحه هم رد شود (مثل token‌های یکبارمصرف یا sign‌شده با IP)، فقط با کلیک روی لینک خود در صفحه دانلود می‌شود.
- روش جایگزین fetch برای فایل‌های بالای ۱۵۰MB کار نمی‌کند (محدودیت حافظه)؛ برای فیلم‌های بزرگ فقط روش مستقیم معتبر است.
- المان‌های داخل **Shadow DOM** اسکن نمی‌شوند.

## ساختار پروژه

```
media-catch/
├── manifest.json        # تعریف افزونه (MV3)
├── background.js        # service worker: دانلود، راست‌کلیک، تاریخچه، بج تب
├── content.js           # تشخیص رسانه + دکمه هاور + پنل صفحه
├── content.css          # استایل اجزای تزریق‌شده
├── popup/
│   ├── popup.html       # پنجره آیکون نوارابزار
│   └── popup.js
├── options/
│   ├── options.html     # صفحه تنظیمات
│   └── options.js
└── icons/               # آیکون‌های 16/32/48/128
```
